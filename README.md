# 🎬 Movie Management System

## 📌 Project Overview
The **Movie Management System** is a console-based application developed in C# using Object-Oriented Programming (OOP) concepts and layered architecture.

The system allows administrators and management staff to manage movies, halls, and customer bookings. Customers can browse available movies and book their preferred movies.

## 🚀 Features

### 1. Admin Module
- Admin login authentication.
- Secure access to administrative functions.
- Records admin login attempts.

### 2. Management Module
- Management login authentication.
- Manage movie records.
- View customer booking records.
- Manage movie details such as name, genre, and price.
- Records management login attempts.

### 3. Customer Module
- View available movies.
- Select movies for booking.
- Enter customer details.
- Book movies in available halls.

### 4. Hall Management
- Manage different movie halls.
- Associate movies with halls.

1. Clone or download the repository.
2. Open the project in Visual Studio or Visual Studio Code.
3. Open the terminal in the project directory.
4. Run the following command:

```bash
dotnet run
```
